# Vorschau: neue Website der SpVgg F.A.L. Fußball

Klickbare Vorschau der neuen Vereinswebsite. **Nicht die offizielle Seite.**
Alle Inhalte in [eckigen Klammern] sind Platzhalter, die Spiele sind Beispieldaten.

- Reine HTML-Seiten ohne Login und Datenbank
- Suchmaschinen sind ausgesperrt (robots.txt, noindex)
- Schrift und Wappen liegen lokal im Ordner `assets`, es werden keine fremden Server geladen

Die echte Website wird später mit WordPress umgesetzt.
